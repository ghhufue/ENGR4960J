# 前端实现与运行说明

本实现采用原生 ES Modules，无应用第三方依赖。开发入口为 [src/index.html](../src/index.html)，HTML、CSS 与 JavaScript 分离；开发阶段通过本地 HTTP 服务运行。

## 模块划分

| 目录 | 职责 |
| --- | --- |
| `src/css/` | 五个样式文件分别负责颜色/尺寸、基础规则、布局、组件与屏幕适配 |
| `src/js/core/` | 状态与 localStorage、版本关联复核、输入及模板检查、纯工具函数 |
| `src/js/i18n/` | 英文资源、带参数系统提示；`core/i18n.js` 管理当前语言及浏览器偏好 |
| `src/js/features/analysis/steps/` | 完整 10 步的独立配置；新增字段与选项修改对应步骤文件 |
| `src/js/features/` | 来源文献、成员及迭代反思、项目备份和人工笔记导出 |
| `src/js/ui/` | 通用字段、分析记录、页面呈现和线性图标 |
| `src/js/app.js` | 路由、事件绑定、焦点/参考区/对话框等交互协调 |
| `scripts/` | 开发服务器、模块检查、单文件构建和可选 Chromium 浏览器检查 |
| `tests/` | 存储、恢复、分支保留、引用、模板检查与构建回归测试 |

页面组件通过步骤配置创建实际可编辑控件。相同的关联、选项互斥、条件字段与检查规则由公共模块处理，避免每个步骤另写一套逻辑。

## 开发与发布

- 在仓库根目录运行 `npm run dev`，打开 `http://127.0.0.1:5173`。
- 运行 `npm run check` 检查语法、导入路径，并在内存中验证单文件打包，不生成正式发布文件。
- 运行 `npm test` 执行核心行为回归测试。
- 可选运行 `node scripts/browser-check.mjs`：需要本机 Chromium 和支持原生 WebSocket 的 Node.js 22+。使用隔离的临时浏览器资料，不读取日常浏览器账号；截图和下载测试文件保存在 `.tmp/`。
- **最终发布时**运行 `npm run build`，生成 `dist/index.html`。CSS 和模块代码内联，使用标准浏览器脚本启动，可直接以本地文件打开。

构建器按本项目命名导入/导出构建模块依赖图，拒绝循环导入及外部包；如以后采用框架或第三方应用依赖，需要升级构建方案。

## 已实现功能

- 案例概览、成员与贡献、全 10 步分析、来源库、开发迭代、三道反思题、完成检查。
- 固定单选、候选多选、其他内容、互斥选项、已有记录搜索及新增关联入口。
- 焦点切换保留各自理由，原则适用/排除切换保留两个分支；当前笔记只导出激活分支。
- 事实、信息缺口和假设分开记录；缺口可建立假设或补充事实。
- 复核发现可登记新问题/事实/缺口，新问题进入解决方案的覆盖检查。
- 短期与长期方案在宽屏并排，窄屏上下排列；约束与方案通过关联材料返回修改。
- 自动本地保存及可见失败提示；JSON 完整备份、确认后导入、TXT 人工分析笔记。
- 引用材料版本变化会使相关步骤显示待复核；按引用链追踪资料变化，并处理循环引用。
- 归档与恢复保留关联；有引用或焦点历史的记录不能直接永久删除。
- 桌面、窄屏导航与只读展示模式。
- 顶部亮色/深色切换，使用主题 tokens 适配全部组件；偏好独立保存在浏览器，不进入案例备份，切换不重建当前编辑区。
- 顶部中英文切换，覆盖完整 10 步及支撑页面的标签、引导、选项、提示、验证和弹窗；界面语言刷新可恢复。

## 中英文适配规则

默认中文，顶部 `EN / 中文` 按钮切换英文与中文。`src/js/i18n/en.js` 以原始中文文案为键提供英文翻译，`patterns.js` 处理带字段名、编号及数量的系统提示。用户分析正文、案例名称、资料标题和自定义内容直接显示原文，不经过翻译函数。

已有记录继续使用原有字段编号、中文选项值和状态，英文只改变显示标签。因此条件展开、选项互斥、复核指纹和旧 JSON 备份继续兼容。语言偏好使用独立浏览器存储键，不属于项目数据。

切换保持当前步骤、展开的编辑记录、筛选和说明内容，更新页面 `lang`、标题及可访问性标签。英文长文案可换行；窄屏顶部操作使用有明确名称的图标按钮。

TXT 笔记的系统标题与选项标签使用当前界面语言，人工内容保持原文；JSON 备份完整保留原始值。新增字段、选项或提示时同步增加语言资源，并运行语言覆盖与兼容性测试。

## 使用边界

课程原则清单需依据实际材料录入。背景简介不被自动转为已核查事实。程序不使用在线 AI 自动完成伦理分析，也不自动撰写报告或三道反思回答。

字数只是估算，中文计数口径、参考文献适用性与 APA 7、事实真伪及伦理判断需人工核对。截图仅登记文件索引，实际图片需要另外整理。

离线模式仍使用浏览器草稿和 JSON 备份。运行 `npm run server` 后可连接多人协作，采用字段修改前快照比较、数组并集及人工冲突裁定，SQLite 保存状态与历史。运行与协议见 [后端使用说明](backend-sync-usage.md)。时间线、相反假设并排比较、完整关系图和截图附件存储仍属于后续增强。

浏览器测试产生的 `.tmp/release-qa.html` 仅验证最终单文件格式；正式交付文件始终由最终发布命令写入 `dist/`，开发源码不被打包结果替代。

GitHub Pages 使用 `src/js/core/sync-config.js` 配置的公网 API；本机和后端自带页面保持同源请求。正式后端通过 `npm run server:public` 启动，按明确的来源列表响应 CORS 预检及带令牌的请求。同步缓存按 API 来源隔离，避免不同服务器之间复用待提交草稿。
