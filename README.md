# 工程伦理分析工作台

依据 `docs/` 下的交互设计、点选清单及 UI Design System 实现，覆盖完整 10 步分析。分析答案由组员填写，程序提供记录、关联、检查和复核，不调用在线 AI 生成案例结论或报告正文。

## 开发运行

需要 Node.js 24 或更新版本，无需安装应用依赖。

```powershell
npm run dev
```

打开 http://127.0.0.1:5173。开发入口是 `src/index.html`；开发版使用标准 ES Modules，需要通过本地服务器打开，不能直接双击文件加载模块。

```powershell
npm run check
npm test
```

检查模块语法、导入路径、核心状态与关联行为，并在内存中验证打包；不会生成正式发布文件。

## 最终发布

开发阶段维护分离文件。需要最终发布时运行：

```powershell
npm run build
```

生成 `dist/index.html`，内联 CSS 和模块打包代码，无外部字体、框架或 API 依赖，可直接在浏览器打开。该命令不会修改 `src/` 文件。构建器仅面向本项目的本地命名导入与命名导出，未来引入第三方包时需升级构建方案。

## 目录

| 路径 | 职责 |
| --- | --- |
| `src/index.html` | 页面壳、样式与模块入口 |
| `src/css/` | Design tokens、基础样式、布局、组件与响应式规则 |
| `src/js/core/` | 状态、持久化、复核依赖、模板验证及通用工具 |
| `src/js/i18n/` | 英文界面资源与动态系统提示翻译；中文使用原始文案 |
| `src/js/features/analysis/steps/` | 10 个独立步骤的字段、选项、条件分支 |
| `src/js/features/` | 来源、反思、备份与笔记导出 |
| `src/js/ui/` | 控件、记录、页面和图标 |
| `src/js/app.js` | 页面路由、交互协调与事件绑定 |
| `scripts/` | 本地服务器、校验与最终单文件构建 |
| `tests/` | 核心行为回归检查 |

## 数据与使用

- 离线草稿保存在当前浏览器；连接协作后，已提交内容会同步到其他成员。尚未联网的草稿仍在原设备，请定期导出 JSON 项目备份。
- JSON 备份保留记录、关联、复核状态与未激活的说明分支。导入时先导出当前内容，再整份替换。
- TXT 分析笔记按步骤整理已输入内容，保留复核记录与来源，不生成报告正文；正式报告仍按 LaTeX 模板自行撰写。
- 课程伦理原则清单需依据实际课程材料录入，不提供假定的完整清单。
- 截图只保存文件名索引，实际截图需另行保存和提交。
- 中文字数不冒充英文 words，计数口径需按课程要求人工确认。
- 归档可恢复；有引用的归档记录不会被静默删除。
- 顶部太阳/月亮按钮切换亮色与深色；主题偏好保存在当前浏览器，刷新可恢复，不改变案例内容或复核状态。
- 顶部 `EN / 中文` 按钮切换界面语言；导航、字段、选项、提示、检查结果、弹窗和笔记标签随语言切换，分析正文及案例名称保留原文。语言选择独立保存在浏览器，旧 JSON 备份无需转换。

## 多人同步后端

运行 `npm run server`，打开 http://127.0.0.1:5173，点击顶部“连接协作”，本机开发令牌可留空。后端同时提供页面和 API，不要与 `npm run dev` 同时占用该端口。

按字段修改前快照检查：字段未变化则保存新值，已变化则提交到人工裁定队列；文字数组直接取去重并集。SQLite 保存团队当前内容、作者、历史快照和冲突，重启后继续加载。数组合并不会自动移除已有项。

局域网成员令牌、启动配置、冲突裁定、API 与备份方法见 [字段级后端使用说明](docs/backend-sync-usage.md)。运行 `npm test` 验证后端与同步行为，`npm run test:sync-browser` 执行双 Chromium 页面验证。

GitHub Pages 版本通过 `https://api.jixrclub.com` 同步；本机和后端自带页面继续使用同源 API。首次运行 `npm run sync:members` 生成私有成员配置，再运行 `npm run server:public` 启动持久化公网后端。此模式默认只监听 `127.0.0.1:5173`，由 Sakura FRP 转发，允许 `https://ghhufue.github.io` 跨域访问，所有项目读写仍要求成员令牌。前端地址配置在 `src/js/core/sync-config.js`；令牌与数据库不随 GitHub Pages 发布。
